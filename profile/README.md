<h2>一、原生要同时满足三个条件</h2>
<p>第一层是注册地，whois 里的国家字段指向韩国。第二层是归属主体，ASN 属于本地运营商而不是数据中心。第三层是路由，从公网到该地址的最后一跳落在家庭宽带汇聚设备上。</p>
<p>三层都满足才算严格意义的原生。多数商家只能满足前两层，第三层因为转售结构拿不到。这类地址在常规查询里看着正常，遇到深度检测就会露出破绽。</p>

<h2>二、三种常见的伪原生</h2>
<p>第一种是机房段改注册信息，把 IDC 地址的联系人改成韩国本地主体，ASN 却没变。第二种是住宅段二次分配，上游确实是家庭宽带，但一个地址切给几十个下游用户。</p>
<p>第三种是跨境转发，入口在韩国，实际出口在别处，延迟曲线会露出马脚。三种做法都能通过简单的归属查询，但都经不起端口扫描加路由追踪的组合检测。</p>

<h2>三、五种自己就能做的检测</h2>
<p>一是 whois 查注册机构与国家字段。二是 ASN 反查，看这个段挂在谁名下。三是 traceroute，看最后一跳的设备与地理位置。四是端口扫描，住宅段通常只开很少的端口。</p>
<p>五是连续多日记录延迟与丢包。机房段的曲线更平，家庭宽带有明显的晚高峰波动。五项交叉看，单一指标都可能被伪装，组合起来判断的准确率高很多。</p>
<h3>ASN 反查怎么读</h3>
<p>把地址丢进 ASN 查询工具，结果里类型字段若显示托管或商业网络，基本可判定为机房。显示运营商且公司名是本地电信，才符合住宅属性，这一步建议放最前面做。</p>
<h2>四、三类渠道的差别</h2>
<p>直采是直接对接韩国本地接入商，价格低、可控性强，但门槛高，通常要韩语沟通与本地付款方式。代理是中间商，交付快、支持中文，加价明显，稳定性取决于上游。</p>
<p>二手是从其他用户手里转租，最便宜也最不稳定，地址可能带着前任的使用痕迹。预算紧可以短用，长期业务不建议把核心账号放在这上面。</p>
<h2>五、下单前要问的九个参数</h2>
<p>要问地址段、ASN、是否独享、是否固定、可换次数、带宽上限、并发连接数、支持协议、交付形式。九项里独享与固定最影响体验，别只盯单价。</p>
<p>还要问计费口径与超额规则。有的按连接数，有的按流量，有的按时长，混着算容易超预算。把这些写进订单备注，后面有争议时有据可依。</p>
<h2>六、买到之后怎么用</h2>
<p>先隔离，把新地址放在独立环境里跑两周，别直接上主账号。再绑定，一个地址固定给一个主体。然后监控，记录登录地点变化与验证触发频率。</p>
<p>出现异常先换地址而不是换账号。账号本身往往没问题，问题多在地址的历史记录。长期看，保持地址与使用习惯一致，比频繁更换更省事。</p>
<h2>常见问答</h2>
<h3>韩国原生 IP 和韩国住宅 IP 是同一个概念吗？</h3>
<p>答：不是。住宅 IP 描述地址属性，原生 IP 强调没有被二次分配、注册信息与使用地一致的完整链路。市面上标称原生的不少其实是住宅段二次分配。</p>
<h3>自己检测需要什么工具？</h3>
<p>答：whois 查询、ASN 反查、traceroute、端口扫描、延迟记录，都有免费在线工具或命令行实现。关键是连续多天记录，单次结果说明不了问题。</p>
<h3>价格差三倍，贵的那个一定更好吗？</h3>
<p>答：不一定。贵的通常承诺独享与固定，但上游同样拥挤时体验差别有限。判断标准是业务对地址历史是否敏感，登录类值得付费，抓取类未必。</p>
<h3>原生 IP 会被平台判定为代理吗？</h3>
<p>答：有可能。判定依据不只看地址属性，还包括指纹、时区、语言与登录行为。地址干净只是基础，环境不一致时照样会被拦。</p>
